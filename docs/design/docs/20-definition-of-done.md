# Definition of Done

## MVP

A release qualifies as MVP when it can:

- accept a local or GitHub repository
- discover common project structures
- identify standard Agent Skills
- inventory components
- map basic capabilities
- build dependency/relationship graphs
- identify documented findings with evidence
- distinguish facts from inference
- produce a static HTML report
- export canonical JSON state
- run without write access
- pass fixture-based tests

## V1

Additionally:
- multi-repository analysis
- GitHub research
- candidate comparison
- capability gap analysis
- unused candidate detection
- improvement proposals
- creation proposals
- plugin/Skill integration
- human approval workflow
- Draft PR generation
- verification and before/after comparison

## V1 safety gate

No merge, deletion, deployment, credential modification, or permission escalation without explicit policy authorization.
